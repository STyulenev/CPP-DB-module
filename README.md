# CPP-DB-module

## Описание

Примеры различных подходов для работы с БД.

## Структура проекта

```
CPP-DB-module
.
│
└───build
│   │
│   ├──.gitignore
│   └───... (промежуточные файлы/директории сборки)
│
└───examples (примеры)
│   │
│   ├───db1_examples/
│   ├───db2_examples/
│   ├───utility_example/
│   └───CMakeLists.txt
│
└───src
│   │
│   ├───db1/
│   ├───db2/
│   ├───utility/
│   └───CMakeLists.txt
│
├───.gitignore
├───CMakeLists.txt
├───main.cpp
├───conanfile.txt
└───README.md
```

* db1 - модуль для работы с БД, в котором основной код находится в Db-классе, а в зависимости от типа БД вызывается свой Query-обработчик. Данные из таблицы сериализируются в entity-классы через table-классы.
* db2 - модуль для работы с БД, который расширяет db1 с использование DTO и DOA с использованием множества интерфесов. Код, для работы с каждой из БД, выносится в отдельный класс.
* utility - вспомогательные файлы/классы для работы с БД.

## Сборка проекта

1. Необходимо скачать и установить Conan ([Ссылка на пакетный менеджер Conan](https://conan.io/ "Conan")).
2. Создать профиль:

```bash
conan profile detect --force
```

3. Сгенерировать вручную (если нужно) CMake файлы для поиска библиотек в папку build:

```bash
conan install . --output-folder=build --build=missing
```

> Если библиотек нет на локальной машине, Conan скачает их из conan-center и соберёт

4. Собрать проект (cборку можно производить из IDE или из папки build командами):

```bash
cmake ..
make
```
> Для debug - "cmake -DCMAKE_BUILD_TYPE=Debug ..", для release - "cmake -DCMAKE_BUILD_TYPE=Release .."
